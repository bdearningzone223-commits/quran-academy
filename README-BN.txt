QURAN ACADEMY WEBSITE

1. Extract this ZIP.
2. Put your final Android APK file in this same folder as index.html.
3. Rename the APK exactly to: quran-academy.apk
4. Upload the complete folder contents to your web hosting's public_html folder.
5. Open your domain to see the landing page.

IMPORTANT:
The supplied Quran Academy ZIP contained Android project source files and images, but no compiled .apk file. The Download APK button is prepared to download quran-academy.apk after you add the real APK.

Included:
- index.html
- assets/ (app artwork and images)
